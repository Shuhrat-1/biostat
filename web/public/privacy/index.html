Privacy

Last updated: 2026-11-21.

Your data stays in the browser

The file you open in BioStat is read and analysed on your computer: the computation runs in the browser (Python in Pyodide). Neither the file nor the results are sent to a server.

This was checked with a network log of the built site: while loading a file, computing and exporting, the browser sends nothing — it only fetches the site's own files (GET requests, not a single POST).

Who sees your IP address

Cloudflare — the host of biostat.app: when you open the site, the browser fetches the page, the code, the computing core and Python (Pyodide) from it.

jsDelivr — the network that delivers the Python packages: when you open the site, the browser fetches 11 package files from it (numpy, scipy, pandas, statsmodels and their dependencies). If the browser has kept them in its cache, it may take them from there.

There are no other requests: no analytics, no ads, no fonts or images from other sites.

Network error reports (NEL)

Cloudflare adds the Report-To and NEL headers to the site's responses. With them, the browser may send Cloudflare a report if a page failed to load because of a network error. Successful loads are not reported (success_fraction: 0). The contents of your files are never in such a report: they do not leave the browser.

What the browser stores

localStorage — only the interface language you chose (key biostat.lang). No cookies. No analytics or counters. No Service Worker or application cache.

In the tab history the app marks its own entry with {biostat: "app"}, so that the “← Back to BioStat” link returns you to the open calculation. The mark holds no data from your file and disappears with the tab history.

Exports

JSON, CSV, Excel, PNG and SVG files are created in the browser and saved to your computer. From then on they are your responsibility. An export contains the results and the column and group names; for many methods also per-observation values (fitted values, residuals) from which part of the data can be reconstructed. JSON and Excel also hold the name, size and SHA-256 of the source file.

Tip: de-identify your data

If the analysis does not need identifiers, remove them before loading: names, addresses, animal or patient numbers and anything else that could identify a person or a farm. The computation needs only numbers and groups.
