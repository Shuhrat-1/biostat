Средние групп с SED и LSD

Каковы средние вариантов и насколько точно оценена разность любых двух из них? Метод даёт средние с SEM и ДИ по общей дисперсии ANOVA, SED и LSD — наименьшую значимую разность.

Идея

После ANOVA дисперсия внутри групп оценена по всем данным сразу — это MSWMS_W (в книге s2s^2) на N − t df. Её и берут для каждой средней: SEM = √(s²/n), а не SD своей группы. Оценка устойчивее, df больше, чем у отдельной группы (Welham, стр. 84–85).

Для разности двух средних ошибка — SED; она всегда больше SEM. SED, умноженная на квантиль t, — это LSD: разность больше LSD значима на 5 %, если это одно, заранее выбранное сравнение (Welham, стр. 85–88). Для многих пар подряд LSD без поправки даёт слишком много ложных находок (Welham, стр. 195–199).

Средние и их ДИ

SEMj=s2/nj=3.91,yˉj⋅±tN−t[0.025]⋅SEMj,t16[0.025]=2.120\mathrm{SEM}_j = \sqrt{s^2/n_j} = 3.91,\qquad \bar y_{j\cdot} \pm t_{N-t}[0.025]\cdot\mathrm{SEM}_j,\qquad t_{16}[0.025] = 2.120

s2=MSWs^2 = MS_W = 76.35 на N − t = 16 df (Welham, стр. 84–85).

SED и LSD

SEDjk=s2(1nj+1nk)=5.53,LSD=tN−t[0.025]⋅SED=11.72\mathrm{SED}_{jk} = \sqrt{s^2\left(\frac1{n_j}+\frac1{n_k}\right)} = 5.53,\qquad \mathrm{LSD} = t_{N-t}[0.025]\cdot\mathrm{SED} = 11.72

При равной повторности SED и LSD одни на все пары. ДИ разности: (yˉj⋅−yˉk⋅)±LSD(\bar y_{j\cdot} - \bar y_{k\cdot}) \pm \mathrm{LSD} (Welham, стр. 85–88).

На примере

Welham, Table 4.1: длина корней (см) при четырёх концентрациях кальция, по 5 горшков. Средние: A 64.2, B 75.8, C 67.2, D 45.4; SEM 3.91, 95 % ДИ для A — 55.9…72.5. SED 5.53, LSD 11.72. Разность B − A = 11.6 чуть меньше LSD: ДИ -0.1…23.3 задевает ноль, P = 0.052 — как в книге. D отличается от A, B и C (P: 0.004, < 0.001 и 0.001) — без поправки на множественность; Тьюки на тех же данных — на странице метода Тьюки.

Welham et al. (2015), стр. 84–88.

Сильные и слабые стороны

Сильные стороны

  • Точнее, чем SD каждой группы: одна s2s^2 по всем данным, больше df (Welham, стр. 84–85).
  • Прямая мера для сравнения: одна полоса LSD рядом со средними говорит больше, чем ± SD каждой группы (Welham, стр. 87–88).
  • ДИ разности, а не только P (Welham, стр. 85–88).
  • Неравная повторность допустима: у каждой пары своя SED (Welham, стр. 85–86).

Слабые стороны

  • Без поправки на множественность: 15 независимых тестов на 5 % дают хотя бы одну ложную находку с вероятностью 0.54 (Welham, стр. 195–196). При трёх и более группах метод предупреждает об этом [BioStat].
  • «Защита» значимым F не помогает: возможны и значимый F без значимых пар, и значимые пары при незначимом F (Welham, стр. 198–199).
  • Требует однородных дисперсий: общая s2s^2 неверна, если разброс групп различается (Welham, стр. 84–85).
  • Только без блоков: для опыта с блоками — сравнения средних с колонкой блока [BioStat].

Welham et al. (2015), стр. 84–88, 195–199; [BioStat].

Как метод выбирает карта

Путь к листу

Анализ отклика›Непрерывный›Различия›Независимые единицы›Без блоков или полные блоки›Один фактор›Три и больше групп›После ANOVA›Средние, SED, LSD

Шаг «После ANOVA» (B5) карта предлагает после листьев сравнения нескольких групп. Какие сравнения делать — выбор пользователя: он зависит от вопроса опыта, а не от данных (Welham, стр. 201–205). Этот лист — для таблицы средних и одного-двух заранее выбранных сравнений. При роли «блок» карта помечает этот лист «без блоков» и подсказывает B5.4: средние, SED и LSD модели с блоками уже даёт ANOVA с блоками, сравнения — по модели с блоками.

Подсказки шага: B5.1 — уровни фактора числа (дозы): тренд вместо попарных сравнений; B5.2 — в факторе есть уровень с названием «контроль»: сравнения с контролем по Даннету.

Что карта проверит на этом листе

  • B5.1 (подсказка) Уровни фактора — числа, не коды 1…k: возможно, это дозы.
  • B5.2 (подсказка) Есть уровень с названием «контроль» (и уровней не меньше трёх).
  • B5.4 (подсказка) Колонке назначена роль «блок»: сравнения — по модели с блоками.

Что дальше

Если нужны все пары — метод Тьюки; против контроля — Даннет в сравнениях средних. Если цель — показать, что различий нет, это другая задача: тест эквивалентности (TOST); незначимая разность отсутствия различий не доказывает (Welham, стр. 253).
