Конфиденциальность

Последнее изменение: 21.11.2026.

Данные остаются в браузере

Файл, который вы открываете в BioStat, читается и считается на вашем компьютере: расчёт идёт в браузере (Python в Pyodide). Файл и результаты на сервер не отправляются.

Это проверено журналом сетевых запросов собранного сайта: при загрузке файла, расчёте и всех выгрузках браузер ничего не отправляет — только получает файлы сайта (запросы GET, ни одного POST).

Кто видит ваш IP-адрес

Cloudflare — хостинг biostat.app: при открытии сайта браузер получает с него страницу, код, расчётное ядро и Python (Pyodide).

jsDelivr — сеть доставки пакетов Python: при открытии сайта браузер получает с неё 11 файлов пакетов (numpy, scipy, pandas, statsmodels и их зависимости). Если браузер сохранил их в своём кеше, он может взять их оттуда.

Других запросов нет: ни аналитики, ни рекламы, ни шрифтов и картинок с чужих сайтов.

Отчёты об ошибках сети (NEL)

Cloudflare добавляет к ответам сайта заголовки Report-To и NEL. По ним браузер может отправить Cloudflare отчёт, если страница не загрузилась из-за сбоя сети. Об успешных загрузках отчётов нет (success_fraction: 0). Содержимое ваших файлов в такой отчёт не попадает: оно не покидает браузер.

Что хранится в браузере

localStorage — только выбранный язык интерфейса (ключ biostat.lang). Cookie нет. Аналитики и счётчиков нет. Service Worker и кеш приложения не используются.

В истории вкладки приложение помечает свою запись меткой {biostat: "app"}, чтобы ссылка «← Вернуться в BioStat» вернула к открытому расчёту. Данных из файла в метке нет; она исчезает вместе с историей вкладки.

Выгрузки

JSON, CSV, Excel, PNG и SVG создаются в браузере и сохраняются на ваш компьютер. Дальше за них отвечаете вы. В выгрузке — результаты расчёта и имена колонок и групп; у многих методов ещё значения по наблюдениям (подогнанные значения, остатки), по которым часть данных можно восстановить. В JSON и Excel — также имя, размер и SHA-256 исходного файла.

Совет: обезличьте данные

Если для анализа не нужны идентификаторы, уберите их до загрузки: имена, адреса, номера животных или пациентов и другие сведения, по которым можно узнать человека или хозяйство. Для расчёта нужны только числа и группы.
