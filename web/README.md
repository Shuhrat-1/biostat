# BioStat — фронтенд

## Запуск (Windows 11 / VS Code)

```bash
# 1. Из корня проекта — упаковать ядро для браузера
python build_core.py

# 2. Установить зависимости и запустить дев-сервер
cd web
npm install
npm run dev
```

Откроется `http://localhost:5173`. Первая загрузка занимает 20–60 секунд:
браузер скачивает Pyodide с numpy, scipy и statsmodels (несколько десятков МБ).
Дальше всё кешируется.

## Что должно произойти

Экран покажет таблицу сверки: те же расчёты выполняются в браузере через
WASM, значения сравниваются с эталонами, полученными в Python на десктопе.
Все строки должны быть отмечены `✓`.

## Важно

После любого изменения в `core/` заново запусти `python build_core.py` —
иначе браузер получит старую версию ядра.
